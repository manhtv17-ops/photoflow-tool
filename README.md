# PhotoFlow

Client-side image enhancer / social optimizer built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import this folder/repo into Vercel or run `vercel` from the project directory.

### V1 features
- Drag/drop image upload
- Before/after slider
- 1x / 2x / 4x upscale
- Natural Photo enhancement
- Social media crop presets
- JPEG quality control
- Client-side processing only

### Safety / provenance
This build intentionally does not spoof camera EXIF, remove C2PA provenance, or try to evade platform AI-content labels.
